# Lumigen v0.4.2-beta

Fifth beta release of **Lumigen**, introducing AI image upscaling with FAL.ai and Topaz models, asset stacking and version management in the gallery, enhanced style management with prompt template injection, and studio generation workflow refinements.

> [!NOTE]
> Beta release: This release introduces database schema updates for AI image upscaling models and asset stacking. Please run `alembic upgrade head` after updating your installation. Report any issues on GitHub.

---

## Highlights

- **AI Image Upscaling (FAL.ai & Topaz)**: High-resolution image upscaling powered by FAL.ai, featuring Topaz and creative upscaler models with customizable creativity, resemblance, and scaling factors.
- **Asset Stacking & Version Groups**: Group iterations, variations, and upscaled assets into cohesive stacks with visual badges, collapsible views, and multi-version browsing in the gallery inspector.
- **Enhanced Style Management**: Rebuilt style service and admin management interface with categorized presets, dynamic prompt templates, and direct studio injection.
- **Refined Studio & Prompt Composer**: Overhauled generation controls and prompt composer with streamlined aspect ratio selection, parameter toggles, and responsive layouts.
- **Robust Background Queue**: Seamless generation queue feedback, active status updates, direct cancellation, and one-click retry for failed tasks.
- **Administrative Configuration**: Dedicated upscale model management tab in the Admin dashboard for configuring models, endpoints, and default upscale settings.

---

## What's New

### AI Image Upscaling

- **FAL.ai Upscale Adapter**: Native integration with FAL.ai upscaler APIs (`fal_upscale_adapter.py`) supporting Topaz Photo AI and creative image enhancement models.
- **Interactive Upscale Dialog**: New `UpscaleModal.vue` accessible directly from generation cards and the gallery asset inspector, offering real-time configuration of scale factors (2x, 4x), resemblance, and creativity.
- **Lineage Tracking**: Upscaled assets automatically retain lineage to their source generations, maintaining linked metadata sidecars and generation prompts.
- **Admin Upscaling Tab**: Comprehensive administration panel (`UpscalingTab.vue`) allowing admins to register new upscale models, modify API targets, and designate default upscale presets.

### Asset Stacking & Gallery Organization

- **Stacking Data Schema**: Database migration `20260918_0027_add_stack_columns_to_assets.py` adding `stack_id`, `stack_order`, and `is_stack_primary` fields to the asset model.
- **Visual Stack Badges**: Gallery cards feature version counter badges (e.g. `📚 3`) to immediately identify multi-version asset groups.
- **Collapsible Gallery Filtering**: New stack filter options in `GalleryFilters.vue` to display only primary assets or expand all versions.
- **Batch Grouping**: Quickly select multiple related images in the gallery and combine them into a unified stack using `BatchActionBar.vue`.
- **In-Depth Version Switching**: `AssetDetailModal.vue` includes an interactive version navigator allowing users to switch between source generations, variants, and upscales seamlessly.

### Style Management & Prompt Injection

- **Categorized Style Presets**: Organized styles by artistic themes and categories for quicker discovery in the generation studio.
- **Prompt Template Expansion**: Support for structured prefix and suffix template injection in `StyleService`, ensuring consistent artistic direction without tedious prompt rewriting.
- **Studio Style Picker**: Redesigned `StylePickerModal.vue` with visual tags, categories, and direct prompt preview.
- **Admin Styles Management**: Refined `StylesTab.vue` with enhanced CRUD controls, validation, and real-time previewing.

### Studio Controls & Generation Workflow

- **Overhauled Prompt Composer**: Modernized layout for `PromptComposer.vue` with responsive action buttons, quick token insertion, and character metrics.
- **Optimized Generation Controls**: Streamlined parameter adjustments in `GenerationControls.vue`, ensuring clean isolation between profile defaults and active session parameters.
- **Studio Navigation Polish**: Enhanced `SessionSidebar.vue` and `AppHeader.vue` with active session indicators, drawer controls, and smoother route transitions.
- **Data Portability**: Hardened JSON import and export flows in `ImportExportService` for styles, models, and administrative profiles.

## Database Migrations

This release includes two new Alembic schema migrations:

1. **`20260917_0026_add_is_default_to_topaz_upscale_models.py`**: Adds default selection support for Topaz / FAL upscale models.
2. **`20260918_0027_add_stack_columns_to_assets.py`**: Adds asset stacking metadata (`stack_id`, `stack_order`, `is_stack_primary`) to support multi-version grouping.

## Upgrade and Setup

### 1. Update Python Dependencies
```bash
pip install -r requirements.txt
```

### 2. Install Frontend Dependencies
```bash
npm install
```

### 3. Apply Database Migrations
```bash
alembic upgrade head
```

### 4. Build Frontend SPA
```bash
npm run build
```

> **Development Mode**: Run `npm run dev` to start Vite with Hot Module Replacement (HMR) alongside the FastAPI backend.

### 5. Start Lumigen
```bash
python -m app.main
```

---

## Migration Notes

- Ensure migrations are applied prior to starting the service with `alembic upgrade head`.
- When updating an existing container deployment, rebuild the Docker image with `docker compose build --no-cache` to ensure the updated frontend bundle and migrations are packaged.
- Existing assets and sessions remain fully compatible and will default to unstacked items until grouped.

---

## Known Limitations (Beta)

- Upscaling requires an active FAL.ai API key configured in the Admin settings.
- Building the frontend locally requires Node.js 20+ and Python 3.12+.
