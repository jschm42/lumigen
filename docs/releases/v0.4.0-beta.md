# Lumigen v0.4.0-beta

Fourth beta release of **Lumigen**, introducing a modern Vue 3 Single-Page Application (SPA) frontend, an intelligent background generation queue with concurrency management, decoupled workflows, and enhanced provider routing.

> [!NOTE]
> Beta release: This release represents a major architectural milestone with the migration to a modern Vue 3 SPA and an asynchronous background generation queue. While core workflows are stabilized and covered by comprehensive tests, please report any UI or queue issues on GitHub.

---

## Highlights

- **Modern Vue 3 SPA Architecture**: Full frontend modernization featuring Vue 3, Vite, Pinia state management, Vue Router, and Tailwind CSS for instant transitions and a polished studio experience.
- **Asynchronous Generation Queue**: Submit multiple generation jobs consecutively without blocking the UI. An intelligent backend FIFO semaphore manages concurrency to prevent provider rate limits and resource contention.
- **Slide-Over Queue Drawer**: Real-time background job monitor accessible from any page, showing active progress, percentage estimates, prompt snippets, and direct cancellation controls.
- **One-Click Retry**: Instantly re-run failed or cancelled generation tasks with identical prompt, model, and resolution settings.
- **Decoupled Profile & Model Workflows**: Freely switch and experiment with different models and parameters without unintentionally modifying or overriding active saved profiles.
- **Intelligent OpenRouter Routing**: Automatic endpoint resolution that dynamically routes requests between multimodal LLM chat completions and dedicated `/api/v1/images` endpoints with aspect ratio translation.
- **Credits & System Diagnostics**: New in-app `CreditsModal` and `SystemInfoTab` for transparent open-source attribution, license tracking, and system diagnostics.
- **Production Container & SSL Support**: Multi-stage Docker build packaging the compiled Vue SPA and FastAPI backend with configurable HTTPS/SSL support.

---

## What's New

### Modern Frontend & User Experience

- **Vue 3 + Vite SPA**: Replaced legacy server-rendered fragments with a reactive Single-Page Application located in `frontend/`, providing instant navigation and smooth micro-interactions.
- **Centralized Pinia State Stores**: Unified reactive stores for authentication, generation jobs, active sessions, gallery filters, and system settings.
- **Modular Studio Components**: Rebuilt header (`AppHeader`), interactive modals (`CreditsModal`), drawer panels, and toast notification systems.
- **Artbook & Session Enhancements**: Set session cover images directly from chat cards, filter sessions dynamically, and export complete session ZIP archives with sidecar metadata.
- **Dynamic Gallery & Asset Inspection**: Refined thumbnail sizing, enhanced rating visibility, batch operations, and in-depth asset detail inspector.

### Generation Pipeline & Concurrency Control

- **Non-Blocking Queue Submission**: The Generate button remains interactive during active runs, displaying queued counts (e.g. `+2`) as jobs are scheduled.
- **Server-Side Concurrency Throttling**: FIFO semaphore queue ensures stable multi-job execution without exceeding provider rate limits.
- **Active Job Cancellation**: Cancel any pending or actively generating task directly from the slide-over queue drawer or generation feed.
- **Instant Job Recovery**: Every failed or cancelled job card includes a **"🔄 Retry"** action that clones and re-enqueues parameters without manual re-entry.

### AI Providers & Model Integration

- **OpenRouter Endpoint Adaptation**: Automatic detection routes standard chat models to completion endpoints and dedicated image models (DALL-E, Imagen 3) to `/api/v1/images`.
- **Expanded Adapters**: Production-tested adapters for OpenAI (DALL-E), Black Forest Labs (BFL Flux), and FAL.ai (Flux, SD, Topaz upscaler).
- **Configurable Timeouts**: Granular timeout settings per provider (`TIMEOUT_OPENAI`, `TIMEOUT_FAL`, `TIMEOUT_LLM`, etc.) configurable via `.env`.

### Admin, System & Compliance

- **System Diagnostics Tab**: Comprehensive system overview displaying environment details, runtime versions, active providers, and storage health.
- **Third-Party Attribution**: Added `CreditsModal` and updated `THIRD_PARTY_LICENSES.md` adhering to license compliance for all included open-source packages and redistributed assets.
- **Hardened Docker & HTTPS**: Multi-stage Docker image with built-in CA certificates and configurable SSL certificate parameters (`LUMIGEN_SSL_CERT_FILE`, `LUMIGEN_SSL_KEY_FILE`).

## Upgrade and Setup

### 1. Update Python Dependencies
```bash
pip install -r requirements.txt
```

### 2. Install Frontend Dependencies
```bash
npm install
```

### 3. Apply Database Migrations
```bash
alembic upgrade head
```

### 4. Build Frontend SPA
```bash
npm run build
```

> **Development Mode**: Run `npm run dev` to start Vite with Hot Module Replacement (HMR) alongside the FastAPI server.

### 5. Start Lumigen
```bash
python -m app.main
```

---

## Migration Notes

- Ensure Node.js 20+ is installed on your host system if building locally.
- If using Docker, rebuild your container image with `docker compose build --no-cache` to ensure the multi-stage frontend build is applied.
- All existing assets, sessions, and SQLite databases remain backwards-compatible.

---

## Known Limitations (Beta)

- Building the frontend locally requires Node.js 20+ alongside Python 3.12+.
- Providers with strict per-minute quota limits may still delay execution if multiple concurrent queue items target the same provider key.
