# Lumigen v0.6.0-beta

Seventh beta release of **Lumigen**, introducing **Agentic Mode** for intelligent multi-image set decomposition and generation powered by LLM reasoning models, native **AI Video Generation** via ByteDance Seedance and fal.ai with ffmpeg poster extraction, pure XML **SVG Vector Graphics** generation, dedicated **Reasoning Models** administration, and automatic gallery stack grouping with one-click full-set ZIP download.

> [!NOTE]
> Beta release: This release introduces database schema updates for reasoning model configurations used by Agentic Mode. Please run `poetry run lumigen-migrate` (or `alembic upgrade head`) after updating your installation.

---

## Highlights

- **🤖 Agentic Mode**: Turn high-level creative prompts (e.g. *"design an RPG item set: potions, weapons, scrolls, shields"*) into cohesive, solitary standalone items using reasoning LLMs (such as DeepSeek, OpenAI o3/o4, Gemini Flash) with a shared visual style anchor.
- **🛡️ Anti-Grid Safeguards**: Automated prompt structuring and negative prompts prevent sprite sheets, icon sheets, and multi-object collage grids, guaranteeing individual centered assets per generation.
- **🧠 Reasoning Models Administration**: New Admin tab (`Admin → Reasoning Models`) allowing administrators to configure, test, and assign LLM reasoning engines with encrypted custom API keys, endpoint configurations, and default flags.
- **🎬 Native AI Video Generation**: Text-to-video and image-to-video workflows powered by ByteDance Seedance (on BytePlus ModelArk) and fal.ai (Kling 2.5/1.5, MiniMax Video-01, Tencent Hunyuan, Luma Dream Machine, LTX Video, and Veo 3).
- **🎞️ First-Frame Poster Extraction & Inline Video**: Automatic extraction of crisp first-frame video posters using `ffmpeg`, seamless inline video playback, and distinct `Video` badges in the gallery and studio feed.
- **📐 Pure Vector Graphics (SVG)**: Support for prompt-to-SVG generation models (e.g. Recraft V3 via fal.ai and Replicate) saved directly in pure XML format without rasterization artifacts.
- **📚 Stack Integration & Structured ZIP Export**: Agentic sets automatically link into gallery stacks (`stack_id`), complete with a one-click **"Download ZIP"** action producing structured, human-readable archives (`01-health-potion.png`, `02-iron-longsword.png`, etc.).

## What's New

### 🤖 Agentic Mode Generation Engine

- **High-Level Decomposition Pipeline**: Integrated `AgenticService` orchestrates prompt decomposition into a structured generation plan comprising set titles, common style anchors, anti-grid negative prompts, and individualized item specifications.
- **Anti-Grid Prompt Engineering**: Eliminates common multi-item collage artifacts by enforcing solitary, centered subjects with negative prompt safeguards against sheets and grids.
- **Collapsible Studio Agentic Controls**: Dedicated toggle in `PromptComposer.vue` revealing reasoning model selection, item count limits (min/max), and real-time generation previews.
- **Progress Tracking & Plan Status**: `GenerationCard.vue` displays live agentic planning indicators, item checklist counters (`🤖 Agentic Mode • 5 / 5 Items`), and individual asset progress.
- **Full-Set ZIP Packaging**: Generate and download structured archive packages containing all generated items in the set alongside sidecar metadata with one click.

### 🧠 Reasoning Models Management

- **Database Schema**: Added `ReasoningModelConfig` model and Alembic migration `20261026_0030_reasoning_model_configs.py` storing model identifiers, provider endpoints, and encrypted credentials.
- **Admin Management Tab**: New `ReasoningModelConfigsTab.vue` supporting full CRUD operations, connection testing, default model assignment, and token pricing definitions.
- **Provider Adapters**: Extensible adapter integration enabling reasoning requests through OpenRouter, OpenAI, and Google Gemini.

### 🎬 AI Video Generation & Media Expansion

- **ByteDance Seedance Adapter**: Direct integration with BytePlus ModelArk for Seedance 2.5, 2.0, and 1.5 Pro video models supporting text-to-video, customized aspect ratios, and durations.
- **fal.ai Video Provider**: Comprehensive video model support including Kling Video (v2.5/v1.5), MiniMax Video-01, Hunyuan, Luma Dream Machine, LTX Video, and Veo 3.
- **Automated Thumbnail Pipeline**: `ThumbnailService` leverages system `ffmpeg` to automatically extract first-frame image posters for fast gallery rendering.
- **Inline Video Player**: HTML5 video playback controls embedded directly in generation cards and the gallery detail inspector.
- **SVG Vector Graphics**: Clean XML asset storage with dedicated `SVG` badges and vector preview rendering.

### 🖼️ Frontend & UX Polish

- **Stack-Aware Feed Cards**: Generation cards detect and display multi-version and agentic sets with direct deep-links to filtered gallery stacks (`📚 View in Gallery Stack`).
- **Unified Media Selector**: Seamlessly switch between image, video, and vector models without losing active session prompt context.
- **Theme & Contrast Polish**: Refined dark/light contrast for agentic badges, parameter pills, and status chips.


## Upgrade Guide

### 1. Pull Latest Changes
```bash
git pull origin main
```

### 2. Update Python Dependencies
```bash
poetry install
```

### 3. Install Node Dependencies
```bash
npm ci    # Windows PowerShell: npm.cmd ci
```

### 4. Apply Database Migrations
```bash
poetry run lumigen-migrate
```

### 5. Build Frontend SPA Bundle
```bash
npm run build
```

### 6. Start Lumigen
```bash
poetry run lumigen
```
