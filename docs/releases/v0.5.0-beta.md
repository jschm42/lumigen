# Lumigen v0.5.0-beta

Sixth beta release of **Lumigen**, bringing project rebranding, comprehensive multi-user management with secure onboarding and password reset flows, 12 supported AI image providers (introducing BytePlus Seedream, xAI Grok Imagine, Ideogram, Replicate, Stability AI, Together AI, and Black Forest Labs), token usage tracking with custom per-model pricing, and a massively overhauled gallery with virtualized rendering and side-by-side comparison.

> [!NOTE]
> Beta release: This release introduces database schema updates for multi-user authentication, general app settings, and per-model pricing rules. Please run `poetry run lumigen-migrate` (or `alembic upgrade head`) after updating your installation.

---

## Highlights

- **Rebranded to Lumigen**: Complete brand transition across the core application, CLI, documentation, and frontend.
- **Multi-User Architecture & Authentication**: Role-based access control (Admin / User), user profile management, secure onboarding, and single-use password reset tokens (SMTP email or admin-generated links).
- **12 Supported AI Image Providers**: Native support for BytePlus ModelArk (Seedream 5.0/4.5/4.0), xAI Grok Imagine, Ideogram 3.0, Stability AI (Ultra, Core, SD 3.5), Together AI, Replicate, and Black Forest Labs (FLUX.2 & FLUX 3), alongside OpenAI, Google Gemini, OpenRouter, fal.ai, and MiniMax.
- **Token Usage Tracking & Custom Pricing**: Real-time token usage reporting per generation, plus customizable pricing models (cost per 1M input/output tokens or per image) in any currency with immutable generation snapshots.
- **Virtualized Gallery & Compare View**: Ultra-fast virtualized asset grid rendering thousands of images with zero lag, grouped by day, accompanied by a synchronized multi-image (2–4) comparison view with linked zoom and pan.
- **Keyboard & Power-User Controls**: Drag-to-select (rubber-band selection), 0–5 numeric ratings, `Space` for quick preview, `Enter`, and shareable URL filter presets.
- **Modern Packaging & Tooling**: Migrated dependency management to Poetry 2.x and introduced `lumigen` and `lumigen-migrate` CLI commands.

## What's New

### 👥 User Management & Security

- **Authentication & Roles**: Admin and User roles with strict tenant boundaries, session cookie isolation, and self-service profile and password updates under `/account`.
- **Password Reset Flow**: Single-use cryptographic reset tokens (60-minute expiry) deliverable via SMTP email or manual admin generation in the admin console. Password changes immediately invalidate all active sessions for that user.
- **Secure Bootstrap Lockdown**: Loopback-restricted root setup (`POST /api/auth/setup-root`) with optional remote opt-in (`ALLOW_REMOTE_SETUP=true`).
- **Encrypted Provider Keys**: Stored securely with Fernet encryption (`PROVIDER_CONFIG_KEY`), configurable globally or per-model.

### 🔌 Expanded Provider Ecosystem (12 Providers)

- **BytePlus ModelArk Adapter**: Support for ByteDance Seedream 5.0, 4.5, and 4.0 with up to 10 reference images, sequential multi-image output, and token usage reporting.
- **xAI Adapter**: Grok Imagine (`grok-imagine-image-2.0`) image generation and editing with usage reporting.
- **Ideogram Adapter**: Ideogram 3.0 Turbo, Default, and Quality models featuring industry-leading typography and style references.
- **Stability AI Adapter**: Native integration for Stable Image Ultra, Core, and SD 3.5 with image-to-image support.
- **Replicate & Together AI Adapters**: Support for any hosted model (`owner/name`) on Replicate, and FLUX variants on Together AI with aspect-ratio-driven dimensions.
- **Native Black Forest Labs (BFL)**: Direct integration with official BFL endpoints for FLUX.2 ([pro], [flex], [klein]) and FLUX 3.

### 💰 Token Usage & Pricing Engine

- **Per-Generation & Session Metrics**: Display real-time token counts for supported providers (OpenAI, Gemini, OpenRouter, BytePlus, xAI).
- **Custom Price Matrix**: Set cost per 1M input/output tokens and/or flat per-image costs per model in `Admin → Models`.
- **Historical Immutability**: Generation costs are snapshotted at creation time, preserving financial accuracy regardless of future rate changes.

### 🖼️ Frontend & Gallery Overhaul

- **VirtualAssetGrid**: DOM virtualization rendering massive image collections smoothly at 60 FPS.
- **CompareModal**: Side-by-side inspection for up to 4 images with synchronized zoom, pan, and detailed metadata overlays.
- **Timeline Organization**: Automatic chronological grouping ("Today", "Yesterday", relative weekday headers).
- **Interactive Batch Selection**: Multi-select images via rubber-band drag, apply batch ratings, tags, stack creations, or bulk ZIP downloads.

## Database Migrations

This release introduces two new Alembic migrations:

1. **`20261019_0028_user_accounts_reset_tokens_app_settings.py`**: Adds user accounts, role definitions, password reset tokens, and application settings.
2. **`20261019_0029_model_config_pricing.py`**: Adds custom pricing schema and token metrics to model configurations.

Apply migrations with:
```bash
poetry run lumigen-migrate
```
